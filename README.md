# Task Manager (Flask) – Azure App Service + Azure Database

## Goal
A web-based Task Manager application where users can create, edit and delete tasks.

## Tech stack
- Backend: Flask (Python)
- Hosting: Azure App Service
- Database: Azure-hosted database (SQL or NoSQL)
- Configuration: Environment variables (no hardcoded credentials)

## Planned features (MVP)
- Create task
- List tasks
- Update task
- Delete task

## Deployment plan
- Deploy to Azure App Service
- Configure DB connection via environment variables
